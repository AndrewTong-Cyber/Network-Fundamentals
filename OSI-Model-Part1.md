# OSI Model - Part 1

## Purpose
- Provides a framework that allows devices to communicate

## Layer 1 - Physical
- Transmits raw bits (1s and 0s)
- Devices: Cables, Wi-Fi, Hubs, Repeaters

## Layer 2 - Data Link
- Uses MAC addresses for Hop-to-Hop communication
- Devices: NICs and Switches

## Layer 3 - Network
- Uses IP addresses for End-to-End communication
- Devices: Routers

## ARP (Address Resolution Protocol)
- Finds a MAC address from a known IP address
- "I know the IP, but I need the MAC"

## Quick Reference
| Term | Definition |
|------|-----------|
| NIC | Physical hardware |
| MAC | Address of the NIC |
| IP | Address of the device |
| Switch | Operates at Layer 2, uses MAC |
| Router | Operates at Layer 3, uses IP |
| Layer 1 | Bits |
| Layer 2 | MAC |
| Layer 3 | IP |
