# Hosts, Clients & Servers

## Key Concepts
- Hosts are any device that sends or receives traffic
- Two types: Clients and Servers

## Client
- Initiates the request

## Server
- Just a computer with software installed
- Responds to specific requests

## IP Address
- Every host has a unique IP address
- Acts as the identity/location of a host on a network

## Network
- A Network is what transports traffic between Hosts
- Anytime two hosts are connected, you have a network
- Can be as small as 2 devices or as large as the internet
